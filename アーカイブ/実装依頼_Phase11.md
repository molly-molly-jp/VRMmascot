## タスク1：11-1 オービットカメラ手動操作

### カメラ方式
**オービットカメラ**（キャラクターを中心に球面上をカメラが回る方式）で実装する。

カメラのパラメータは以下の4つ：

| パラメータ | 意味 |
|-----------|------|
| `targetY` | カメラが注視するY座標（キャラクターのどの高さを見るか） |
| `distance` | カメラとキャラクターの距離（ズーム量） |
| `rotY` | 水平回転角（左から見る・右から見る） |
| `rotX` | 垂直回転角（見上げ・見下ろし） |

### 操作マッピング

| 操作 | 動作 |
|------|------|
| 右クリックドラッグ 左右 | rotY（水平回転） |
| 右クリックドラッグ 上下 | rotX（垂直回転） |
| Ctrl＋マウスホイール | distance（ズーム） |

### 要件

| # | 要件 | 詳細 |
|---|------|------|
| F11-1-1 | オン/オフボタン | 設定UIにカメラ操作オン/オフボタンを追加。オフ中はマウス操作を無視 |
| F11-1-2 | 水平回転 | 右クリックドラッグ左右でrotYを変化させる |
| F11-1-3 | 垂直回転 | 右クリックドラッグ上下でrotXを変化させる |
| F11-1-4 | ズーム | Ctrl＋マウスホイールでdistanceを変化させる |
| F11-1-5 | 録画への影響なし | カメラ操作オン/オフボタンは設定UIに置く。VRMウィンドウには置かない |

### 完了条件
- カメラ操作オンの状態で右クリックドラッグするとキャラクターを中心に視点が回転する
- Ctrl＋ホイールでズームインアウトできる
- カメラ操作オフにするとマウス操作に反応しなくなる

### 完了したら
変更したファイルと変更箇所を報告して止まること。

## タスク2：11-2 プリセット＋リセット

### 要件

| # | 要件 | 詳細 |
|---|------|------|
| F11-2-1 | プリセット保存 | プリセット1〜3の「保存」ボタンで現在のカメラ位置をconfig.jsonに記録 |
| F11-2-2 | プリセット呼び出し | プリセット1〜3の「呼び出し」ボタンで記録したカメラ位置に移動 |
| F11-2-3 | リセット | config.jsonのdefault位置に戻す |

### config.jsonのカメラ設定構造

```json
"camera": {
  "default": { "targetY": 1.4, "distance": 3.0, "rotX": 0.0,  "rotY": 0.0 },
  "presets": [
    { "label": "プリセット1", "targetY": 1.4, "distance": 3.0, "rotX": 0.0,  "rotY": 0.0 },
    { "label": "プリセット2", "targetY": 0.9, "distance": 2.0, "rotX": 0.2,  "rotY": 0.3 },
    { "label": "プリセット3", "targetY": 1.6, "distance": 4.0, "rotX": -0.1, "rotY": 0.0 }
  ]
}
```

### 完了条件
- 設定UIにプリセット1〜3の「保存」「呼び出し」ボタンとリセットボタンがある
- 「保存」を押すと現在のカメラ位置がconfig.jsonのpresets配列に書き込まれる
- 「呼び出し」を押すと記録したカメラ位置に移動する
- 「リセット」を押すとconfig.jsonのdefault位置に戻る

### 完了したら
変更したファイルと変更箇所を報告して止まること。
