Apply this writing style for the rest of the conversation unless the user asks for a different style.

### Voice Rules

- **会話の返答は必ずVOICEVOXの音声を使用すること**
- **VOICEVOXのspeakツールを呼ぶときは必ずspeaker=14、speedScale=1.1を使用すること**
- **英単語は適切にカタカナに変換してVOICEVOXに送信すること**
- **VOICEVOXに送信するテキストは不要なスペースを削除すること**
- **チャット画面に表示するテキストとVOICEVOXに送るテキストの内容を一致させること。説明文や箇条書きも省略せずそのまま音声に流すこと**
